# CareFirst Home Nursing Website

Home page for CareFirst, a home nursing service in Karachi.

## Files
- `index.html`: the home page
- `css/style.css`: all styles and animations
- `js/script.js`: mobile menu and scroll effects
- `images/`: logo and hero photo

## Publish on GitHub Pages
1. Upload all files in this folder to a GitHub repository (keep the folder structure).
2. Go to **Settings > Pages**.
3. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/` after a minute or two.
